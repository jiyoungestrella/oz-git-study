# CSS Grid 실습 정리

## Grid란?

화면을 **행(row)과 열(column)으로 나눠 바둑판처럼** 배치하는 레이아웃 방식.

| | Flex | Grid |
|---|---|---|
| 방향 | 1차원 (가로 **또는** 세로) | 2차원 (가로 **그리고** 세로) |
| 용도 | 메뉴, 한 줄 정렬 | 갤러리, 카드 목록, 페이지 전체 레이아웃 |

---

## 실습 1. 기본 Grid (grid.html)

```css
.container {
    display: grid;
    grid-template-columns: repeat(4, 25%);  /* 열 4개, 각 25% */
    grid-template-rows: 50px 100px;         /* 1행 50px, 2행 100px */
    gap: 10px;                              /* 칸 사이 간격 */
}
```

```html
<div class="container">
    <div class="item">A</div>
    <div class="item">B</div>
    ...
    <div class="item">F</div>
</div>
```

**결과:** A~D가 첫 줄, E~F가 둘째 줄에 자동으로 채워짐

### 주요 속성

| 속성 | 의미 | 예시 |
|---|---|---|
| `display: grid` | 그리드 시작 | |
| `grid-template-columns` | 열 개수와 너비 | `1fr 1fr 1fr`, `repeat(3, 1fr)`, `200px 1fr` |
| `grid-template-rows` | 행 개수와 높이 | `50px 100px`, `repeat(4, 200px)` |
| `gap` | 칸 사이 간격 (`row-gap` + `column-gap`) | `10px`, `0.8rem` |
| `repeat(횟수, 크기)` | 같은 크기 반복 | `repeat(4, 1fr)` = `1fr 1fr 1fr 1fr` |

### `fr` 단위

남은 공간을 나누는 **비율** (fraction).

```css
grid-template-columns: 1fr 2fr;    /* 1:2 비율 */
grid-template-columns: 200px 1fr;  /* 200px 고정 + 나머지 전부 */
```

> ⚠️ `repeat(4, 25%)` + `gap: 10px` → 25% × 4 = 100%에 간격 30px이 더해져서 **오른쪽으로 넘침**
> → `repeat(4, 1fr)`을 쓰면 gap을 빼고 남은 공간을 나눠서 딱 맞음

## 실습 2. 갤러리 (gallery.html)

### grid-template-areas

칸마다 **이름을 붙여서 그림 그리듯** 배치하는 방법.

```css
.container {
    display: grid;
    gap: 0.8rem;
    grid-template-columns: 1fr 1fr 1fr;
    grid-template-rows: repeat(4, 200px);
    grid-template-areas:
        "img1 img3 img3"
        "img1 img4 img6"
        "img2 img2 img6"
        "img5 img5 img5";
}

.img1 { grid-area: img1; }
.img2 { grid-area: img2; }
/* ... img6까지 */
```

- 같은 이름을 여러 칸에 쓰면 그 칸들을 **합쳐서** 차지함
  - `img1`: 세로 2칸 / `img3`: 가로 2칸 / `img5`: 가로 3칸 전체
- 합치는 영역은 반드시 **직사각형**이어야 함

### 이미지를 칸에 꽉 채우기

```css
img {
    width: 100%;
    height: 100%;
    object-fit: cover;      /* 비율 유지하며 꽉 채우고 넘치는 부분은 잘림 */
    border-radius: 0.5rem;
}
```

| `object-fit` 값 | 동작 |
|---|---|
| `fill` (기본) | 칸에 맞게 늘림 (찌그러짐) |
| `cover` | 비율 유지, 꽉 채움 (일부 잘림) |
| `contain` | 비율 유지, 전체 보임 (여백 생김) |

### hover 효과: 마우스 올린 사진만 강조

```css
.container:hover img:not(:hover) {
    filter: grayscale(1);   /* 흑백 */
    opacity: 0.5;           /* 반투명 */
}
```

- `.container:hover` → 갤러리 위에 마우스가 있을 때
- `img:not(:hover)` → 마우스가 **올라가 있지 않은** 사진들만
- 결과: 나머지 사진은 흐려지고, 보고 있는 사진만 컬러로 남음

버튼 누르면 메뉴가 펼쳐지고 접히기

부트스트랩에 JS가 들어 있는 이유

부트스트랩은 CSS만으로 안 되는 움직이는 부품들을 JS로 미리 만들어 놨어요. 그래서 HTML에 이런 줄이 같이 들어가요.

html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

이 파일이 있어야 동작하는 대표 부품:

Navbar 햄버거 메뉴: 모바일에서 ☰ 누르면 메뉴 펼치기
Dropdown: 클릭하면 아래로 목록 열기
Modal: 팝업창
Carousel: 이미지 슬라이드

그래서 HTML에 data-bs-toggle="collapse" 같은 속성이 보이면, "이 요소는 부트스트랩 JS가 클릭을 감지해서 동작시킨다"는 표시예요. 직접 JS 코드를 안 써도 부트스트랩이 대신 해 주는 거죠.

아주 간단한 JS 맛보기
html
<button onclick="alert('안녕하세요!')">눌러보세요</button>

버튼을 누르면 알림창이 뜨는데, onclick 안의 alert(...) 부분이 JavaScript예요.
