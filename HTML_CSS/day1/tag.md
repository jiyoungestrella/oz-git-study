# 🏷️ HTML 필수 태그 개념 

> **💡 HTML 태그?**
> 컴퓨터(브라우저)에게 "여기는 제목이야!", "여기는 사진을 넣어줘!" 하고 용도를 알려주는 이름표

---

## 1. 뼈대와 구조를 잡는 태그

* **`<head>` (머리/설정 영역)**
  * **설명**: 화면에 직접 보이진 않지만, 웹페이지의 제목이나 중요한 설정 정보를 숨겨두는 곳이에요.
* **`<body>` (몸통/화면 영역)**
  * **설명**: 실제로 눈으로 보고 만지는 모든 콘텐츠(글, 사진, 버튼 등)가 들어가는 메인.

---

## 2. 글자와 목록을 쓰는 태그

* **`<p>` (Paragraph, 문단)**
  *  글을 쓸 때 문단과 문단을 깔끔하게 나누어 주는 기본 글상자 태그예요.
* **`<ul>` (Unordered List, 순서 없는 목록)**
  * **비유**: 마트 장보기 **'동그란 점(●)으로 된 체크리스트'**
  * **설명**: 순서가 상관없는 목록을 만들 때 앞에 동그란 점이 붙어요.
* **`<ol>` (Ordered List, 순서 있는 목록)**
  * **비유**: 매겨주는 **'1번, 2번, 3번 번호 매기기 순위'**
  * **설명**: 순서가 중요한 목록(요리 순서 등)을 만들 때 1, 2, 3 숫자가 자동으로 붙어요.

---

## 3. 요소를 넣고 조작하는 태그

* **`<input>` (입력창)**
  * **비유**: 설문조사지의 **'빈칸 뚫린 답안란'**
  * **설명**: 사용자가 키보드로 글자나 비밀번호를 직접 칠 수 있는 빈칸(상자)을 만들어 줘요.
* **`<img>` (Image, 이미지)**
  * **비유**: 액자에 끼워 넣는 **'사진 액자'**
  * **설명**: 웹페이지에 그림이나 사진을 띄워주는 태그 (닫는 태그가 없음)
